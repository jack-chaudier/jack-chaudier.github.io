## Project Rhun

[Project Rhun](https://jack-chaudier.github.io/rhun/) is my research program toward **Pylos-1**: a decoder that treats context as custody and lets loss be visible. The site's `/rhun/` page explains the three ideas behind it (the mirage, context as custody, visible loss) and states plainly where the work stands: no trained Pylos-1 exists and training has not been run. The program record is private; the shipped side is [Pylos](https://github.com/jack-chaudier/pylos), open source.
